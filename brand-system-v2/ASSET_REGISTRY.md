# MotoristaOPS V2 — Registro de ativos

## Status do pacote atual

O pacote contém o arquivo `/landing-v3/logo-oficial.svg`, fornecido no projeto como logo oficial. Ele deve ser aplicado sem redesenho.

## Arquitetura oficial preservada

O sistema aprovado reconhece as seguintes versões já documentadas no material-base:

1. Assinatura vertical oficial — logo completo/master.
2. Assinatura horizontal oficial.
3. Assinatura horizontal compacta.
4. Wordmark / somente texto.
5. Símbolo com estrada.
6. Símbolo simplificado para avatar.
7. Versão para fundo escuro.
8. Versão para fundo claro.
9. Versão monocromática / 1 cor.
10. Versão reduzida / micro aplicação.

## Regra de integridade

Este pacote **não extrai nem reconstrói** variantes a partir de screenshots do Brand Book antigo. Uma variante só deve ser usada como arquivo produtivo quando seu master oficial estiver disponível. Isso evita criar um novo ativo por recorte, redesenho ou aproximação.

## Proteção e mínimos preservados

- Área de proteção: `X = diâmetro do vazio interno do O/pin`.
- Logo completo: mínimo digital de 320 px de altura; impresso de 45 mm de altura.
- Símbolo com estrada: mínimo digital de 64 px de altura; impresso de 12 mm de altura.

## Efeito metálico

O master oficial fornecido possui variação tonal no Champagne. A regra vigente é preservar o ativo como recebido e **não reproduzir esse efeito em novos elementos** até existir especificação produtiva própria. Aplicações operacionais do sistema usam cores planas.
