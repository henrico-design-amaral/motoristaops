# MotoristaOPS V2 — DECISIONS

## 2026-09-01 — V2 clean rebuild
- V2 nasce separada da V1.
- V1 é histórico e fonte de migração seletiva.

## 2026-09-01 — Lifecycle canônico
- Fluxo obrigatório: intenção → definição → PDR → Project Base Pack → Level 0 → referências → protocolos → plano/spec/work session → estratégia/contratos → produção → loop iterativo → validação → consolidação → release → observação/aprendizado.

## 2026-09-01 — Baseline de produto
- Superfícies: Landing, Instagram e WhatsApp Business.
- Instagram baseline: Reels, carrossel e Stories.
- WhatsApp Business é principal canal de contato/conversão.
- Dashboard da V1 não é herdado automaticamente.

## 2026-09-01 — Autoridade e evidência
- Brand Book e assets oficiais são soberanos para identidade.
- Pessoa, carro e contexto real têm preferência sobre imagens genéricas.
- Claims sem proveniência são bloqueados.

## 2026-09-01 — Project Base Pack
- PRODUCT, AGENTS, A11Y, SOURCES e DECISIONS são contratos ativos.
- DESIGN foi ativado no Level 0.

## 2026-09-01 — Level 0 / Brand Book V12

## 2026-09-01 — Referências Stage 5
- `MotoristaOps_Refs` é estudo histórico, não autoridade visual atual.
- Identidade antiga é rejeitada/arquivada; princípios de aplicação podem ser adaptados.
- Gramática urbana luminosa permanece adotada com override V12: campo quieto, cidade baixa, percurso controlado, um destino e luz como acento.
- Referências globais são absorvidas na linguagem MotoristaOPS, não exibidas como dependência estética.

## 2026-09-01 — Protocolos Stage 6
- Stage gate, source/identity preflight, real-asset-first, proveniência, anti-copy, produção seção a seção e triple-check são obrigatórios.
- Mudanças materiais seguem spec → plan → tasks → implement → converge.

## 2026-09-01 — Plano e contratos R1
- Landing é primeira superfície de produção; Instagram e WhatsApp seguem a identidade/narrativa validada.
- Retrato real é âncora preferencial da abertura; carro real é prova em bloco próprio.
- Landing R1 usa HTML semântico + CSS + JavaScript mínimo, sem framework, por ausência de requisito que justifique build/dependências.
- WhatsApp Business é CTA primário; Instagram continuidade secundária.
