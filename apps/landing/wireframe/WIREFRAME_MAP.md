1. Header

9. Instagram continuity
10. Final CTA
11. Footer

## Why this sequence

- Start with identity + value + direct conversion.
- Immediately reduce ambiguity with three concrete operating principles.
- Explain what can be hired before explaining the method.
- Use the method as the main differentiator.
- Translate brand values into observable service behavior.
- Show real evidence before asking the user to trust claims.
- Humanize the service after the user understands what is being bought.
- Use Instagram as continuity/proof, not as the main conversion path.
- Close with one clear WhatsApp action.

## Governance inherited from the curation

- Brand Book / approved decisions / DESIGN.md / A11Y.md outrank references.
- Max 3 primary references per high-fidelity work session.
- No fake testimonials, fake metrics or unsupported claims.
- WhatsApp is primary conversion.
- Real photos beat stock or generated proof.
- Premium functional, never luxury theatre.
- Iconography comes from one consistent public library per surface.
- Dashboard references stay isolated from the public landing.
