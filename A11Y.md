# MotoristaOPS — Accessibility Contract

Status: ACTIVE
Version: 1.0
Date: 2026-09-01
Authority: HenricoOPS `A11Y_GATE.md` + current surface contracts

## Baseline
All user-facing executable MotoristaOPS interfaces target WCAG 2.2 AA unless a stricter current decision applies.

## Required behavior
- semantic structure and meaningful headings/landmarks;
- complete keyboard operation for interactive controls;
- visible focus;
- sufficient text/UI contrast;
- touch targets appropriate to mobile use;
- meaningful alternative text for informative media;
- color is not the sole carrier of meaning;
- zoom/reflow without content loss or uncontrolled horizontal overflow;
- reduced-motion support for non-essential animation;
- responsive composition from mobile upward;
- errors/statuses understandable beyond visual styling alone.

## Surface notes
### Landing
CTA/contact flows, navigation, media and any motion must remain usable under keyboard, zoom, reduced motion and mobile reflow.

### Dashboard
Dense information must preserve reading order, labels, focus behavior, table/card reflow and meaningful status communication.

### Social
Generated visual assets require legibility/contrast review; accompanying channel copy/captions should carry essential meaning that cannot be recovered from imagery alone.

## Exceptions
No project-specific exception is approved by this file. Any exception that weakens the baseline requires an explicit recorded decision and evidence.

## Validation
Apply the global A11Y gate plus protocol-specific/browser validation before acceptance/release.
