# MotoristaOPS V2 — A11Y

Status: ACTIVE CONTRACT
Target: WCAG 2.2 AA

Acessibilidade é gate de produção, não acabamento posterior.

## Regras permanentes
- contraste suficiente para texto, links, CTA e controles;
- navegação completa por teclado;
- foco visível;
- HTML semântico e heading hierarchy coerente;
- imagens informativas com alt útil; decorativas sem ruído para leitor de tela;
- não depender apenas de cor para comunicar estado;
- zoom/reflow sem perda funcional;
- sem scroll horizontal a 320 CSS px;
- áreas de toque adequadas em mobile;
- respeitar `prefers-reduced-motion` quando houver movimento;
- formulários futuros exigem label, instrução e erro associado;
- carrossel só entra se teclado, touch, foco e leitura forem comprovados; empilhamento simples é preferido.

## Landing
CTA principal precisa permanecer alcançável e claro. Imagem da Hero não pode destruir legibilidade da proposta; overlay é ferramenta de contraste, não efeito decorativo.
