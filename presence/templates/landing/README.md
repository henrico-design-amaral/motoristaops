# Templates de landing page

## Princípio

Cada landing é uma instância de um template determinístico.

Não existe fluxo automático imagem -> IA -> layout.

## Famílias iniciais

1. `driver-standard` — motorista particular.
2. `driver-executive` — executivo, aeroporto, corporativo e eventos.
3. `driver-creator` — motorista criador/influenciador.
4. `driver-recurring` — serviços recorrentes.

## Contrato

Todo template recebe dados validados e não possui liberdade para alterar o Brand System.

Campos principais:

- identidade;
- veículo;
- serviços;
- áreas atendidas;
- links sociais;
- Google Business quando aplicável;
- CTA WhatsApp;
- avaliações futuras;
- galeria futura.

## Publicação

Uma página só pode sair de `draft` para `published` depois de:

- dados válidos;
- preview confirmado;
- template/version registrados;
- QA técnico;
- QA visual;
- links válidos;
- acessibilidade mínima;
- Brand Gate.
