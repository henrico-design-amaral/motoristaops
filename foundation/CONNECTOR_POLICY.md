# Connector & Tool Policy

## Princípio

Ferramenta é implementação. Autoridade vem do sistema.

## GitHub
Papel: código, contratos versionados, foundation, Design System, deploy workflows e histórico de decisão executável.

Preferir edição direta via conector. Mudanças estruturais: branch -> PR -> gates -> merge.

## Google Drive
Papel: fontes de trabalho, documentos de projeto, curadoria raw, imagens e materiais colaborativos.

MotoristaOps_Refs é biblioteca raw. Não é autoridade visual.

## Hostinger
Papel: destino de produção. Não usar como superfície principal de edição.

## Metricool / publicação social
Papel: planejamento/publicação/analytics quando conectado e adequado.

Publicação exige peça aprovada e gate social.

## Figma / Canva
Papel: execução visual quando necessário.

Não iniciar MotoristaOPS de template genérico. Assets e tokens oficiais prevalecem.

## Web
Papel: atualidade, pesquisa, benchmark e validação externa.

Resultado web entra como evidência/referência, não como canon automático.

## Geração de imagem/vídeo
Papel: mídia desbloqueada.

Nunca sintetizar identidade protegida ou prova operacional falsa.

## Regra de seleção

Selecionar ferramenta por:
1. fidelidade necessária;
2. capacidade determinística;
3. fonte disponível;
4. verificabilidade;
5. reversibilidade;
6. custo/tempo somente depois dos critérios anteriores.
