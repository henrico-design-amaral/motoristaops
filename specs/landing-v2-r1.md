# Spec — Landing MotoristaOPS V2 R1

Status: READY

## Goal
Criar a página pública principal: simples, forte, humana, real e orientada a contato via WhatsApp Business.

## Must
Assets oficiais; MotoristaOPS unido; categoria MOTORISTA PARTICULAR; retrato real e fotos reais do carro; CTA WhatsApp quando destino verificado; Instagram secundário; mobile completo; HTML semântico, SEO básico, WCAG 2.2 AA; zero claims não verificados; zero overdesign/overlap/SaaS/limousine.

## Functional blocks
Header; Hero; Service/Use cases; Person/Method; Vehicle proof; Trust; Contact; Footer. Podem ser combinados para reduzir redundância.

## Visual contract
Brand Book V12 + DESIGN.md + gramática Stage 5. N2 Ambiente default; N3 Hero apenas na primeira dobra se a marca continuar dominante.

## Non-goals
Booking complexo, login, dashboard, multilanguage, theme switch, chatbot e animação pesada.

## Acceptance
Desktop/mobile QA, brand QA, provenance QA, A11Y, performance, links e imagens responsivas passam triple-check.
