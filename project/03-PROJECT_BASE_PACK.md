# MotoristaOPS V2 — 03 PROJECT BASE PACK

Status: VALIDATED

## OBJETIVO
Transformar definição e PDR em um conjunto mínimo de arquivos canônicos que qualquer executor deve carregar antes de trabalhar no MotoristaOPS V2. O Base Pack não cria estética: define produto, autoridade, leitura, fontes, acessibilidade e decisões.

## ARQUIVOS CANÔNICOS
- PROJECT_LIFECYCLE.md — estágio e progressão.
- project/00-INTENCAO.md — intenção.
- project/01-DEFINICAO_DO_PROJETO.md — fronteiras.
- project/02-PDR.md — requisitos.
- PRODUCT.md — contrato executivo do produto.
- AGENTS.md — contrato dos agentes.
- A11Y.md — acessibilidade permanente.
- SOURCES.md — autoridades, fontes e ativos.
- DECISIONS.md — decisões duráveis.
- DESIGN.md — reservado ao Level 0.
- specs/ — mudanças materiais após protocolos.

## ORDEM DE AUTORIDADE
Decisão explícita atual do usuário → lifecycle canônico → definição/PDR validados → Brand Book e assets oficiais → contratos ativos do Base Pack → referências específicas homologadas → referências globais homologadas → V1 somente como histórico/migração controlada.

## REGRA DE CARREGAMENTO
Nenhum executor começa por código ou referência visual. Primeiro resolve estágio, superfície, escopo/non-goals, fontes aplicáveis, contrato visual quando ativo e eventual necessidade real de intervenção humana.

## CONTRATOS ATIVOS
PRODUCT: ativo. AGENTS: ativo. A11Y: ativo. SOURCES: ativo. DECISIONS: ativo. DESIGN: bloqueado até Stage 4. Referências: disponíveis, porém ainda não curadas para V2. Protocolos: ainda não definidos.

## AUTONOMIA
Pode avançar sem intervenção humana quando a decisão está coberta por fonte canônica, é reversível, não cria promessa/dado/identidade nova, não expande materialmente o escopo e não publica antes do gate correspondente. Conflitos de autoridade, compromissos comerciais/legais, mudanças irreversíveis e escolhas materiais não cobertas devem escalar.

## V1
Nenhum código, layout, dependência ou decisão migra por conveniência. Itens da V1 usam classificação KEEP, ADAPT, RESEARCH, REJECT ou ARCHIVE.
