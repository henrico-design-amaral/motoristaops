## Estratégia de produto
MotoristaOPS V2 não tenta parecer maior do que o serviço. Transforma realidade em confiança: pessoa identificável, serviço compreensível, veículo real, presença consistente e canal direto.

## Conversão
WhatsApp Business = ação primária. Instagram = continuidade secundária. Landing reduz incerteza; não cria funil artificial.

## Visual
Brand Book V12 imutável na identidade; base escura/Marfim/Champagne; atmosfera N2 padrão, N3 abertura; retrato real como anchor humano; carro real como evidência; campo quieto vence decoração.

## Conteúdo
Cada bloco responde uma pergunta real; texto curto, concreto e verificável; não repetir slogan/benefício/CTA mecanicamente; prova distinguida de copy promocional.

## Contrato técnico Landing R1
HTML semântico + CSS moderno + JavaScript progressivo mínimo, sem framework. Racional: uma Landing majoritariamente estática, SEO/performance prioritários e baixa necessidade de estado. Framework só entra quando uma spec futura demonstrar necessidade concreta.

## Implementação
Zero UI kit genérico; tokens do design system; CSS organizado sem abstração prematura; JS apenas para comportamento real; imagens otimizadas; progressive enhancement; reduced-motion; zero secrets no cliente.

## Fidelidade
DIRECTIONAL → ADAPTIVE durante protótipo. Seção aprovada congela anchors e não pode ser redesenhada silenciosamente durante ajuste de outra.

## Social
Reels = movimento/presença; carrossel = progressão de ideia; Stories = proximidade/ação contextual.

## WhatsApp
Atendimento, não interface de marketing; perfil reconhecível, mensagem objetiva, respostas rápidas e continuidade humana.

## Release strategy
Landing local/protótipo → QA por seção → Instagram/WhatsApp → integração → RC triple-check → deploy controlado com rollback.
